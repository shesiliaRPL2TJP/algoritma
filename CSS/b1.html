1. Apa Itu Box Model?

CSS Box Model adalah konsep yang mengatur ukuran dan jarak setiap elemen pada halaman website.

CSS Box Model adalah konsep dasar dalam desain web yang memperlakukan setiap elemen HTML sebagai sebuah kotak persegi panjang (box). Kotak ini menentukan bagaimana ukuran, tata letak, serta jarak antar elemen diatur di dalam halaman web
